## Magic UI pattern references

The `Meteor horizon` and `Venture orbits` previews use Magic UI's Meteors and Orbiting Circles as visual references. They are independent HTML/CSS implementations; no Magic UI source code or dependency is included. The official repository lists MIT licensing, and its component docs describe the meteor shower and orbiting-circle patterns: [Magic UI license](https://github.com/magicuidesign/magicui/blob/main/LICENSE.md), [Meteors](https://magicui.design/docs/components/meteors), [Orbiting Circles](https://magicui.design/docs/components/orbiting-circles). These references were checked on 2026-11-01. The registry records upstream links and the adaptation notes beside each preview. The MIT terms apply to Magic UI's code; they do not license the Observatory's independent implementation.
