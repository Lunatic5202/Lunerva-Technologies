# Contributing

Keep the interface quiet, precise and legible. Follow the LUNEVRA graphite and silver identity, using cyan sparingly for focus and action. Prefer working controls and honest unavailable states over decorative placeholders.

When adding a catalogue record, include provenance and an explicit licence status. Do not execute imported source in the parent application. Keep reduced motion in mind and avoid invented performance figures. Update the relevant documentation when a feature or trust boundary changes.
