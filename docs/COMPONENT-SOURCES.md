# Component sources

This redesign adapts two interaction patterns from [React Bits](https://reactbits.dev/), copied into the repository as editable source rather than added as a runtime dependency.

## Spotlight Card

- Source: [React Bits Spotlight Card](https://reactbits.dev/components/spotlight-card)
- Registry source: [SpotlightCard TypeScript + CSS](https://reactbits.dev/r/SpotlightCard-TS-CSS.json)
- Adapted in: `src/components/SpotlightCard.tsx` and `src/styles.css`
- Use in this site: a restrained cursor-aware light and edge rim around portfolio artwork.

## Shiny Text

- Source: [React Bits Shiny Text](https://reactbits.dev/text-animations/shiny-text)
- Adapted in: `src/components/ShinyText.tsx` and `src/styles.css`
- Use in this site: a single, non-looping material sweep on the hero metadata.

React Bits documents its free component set as MIT + Commons Clause and permits use in personal and commercial projects, while prohibiting redistribution of the components themselves as a standalone library. These components are adapted into Lunerva’s existing visual system and are not exposed as a separate component package.
